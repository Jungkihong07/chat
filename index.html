테마

      👋 시작하기

      • 이름을 먼저 적으세요 — dev는 맨 아래 이름@api-server, 엑셀은 맨 위 fx 왼쪽 칸 (한 번 적으면 기억)
      • 메시지 입력 후 Enter 로 전송
      • 이 안내 다시 보기: 도움말(엑셀: 위 메뉴줄 끝) / ? Help(dev: 아래 상태바) 또는 /help

      🧰 기능

      • 위장 화면 — 대화가 가짜 코드·가짜 실적표 사이에 섞여 보임
      • 보스 키 Esc — 대화만 싹 숨김, 한 번 더 누르면 복귀
      • 접속자 표시 — 하단 👥 / 공동 편집: 에 지금 들어온 사람
      • 입력 중 표시 — 누가 치고 있으면 하단에 분석 중… / 편집 중…
      • 명령어
        • /roll 주사위 굴리기 🎲
        • /shrug ¯\_(ツ)_/¯ 보내기
        • /shake 같은 방 사람들 화면 흔들기 📳
        • /help 이 안내 열기
      • 테마 바꾸기 — 엑셀: 위 메뉴줄 설정 탭 → 리본에서 선택 / dev: 아래 상태바 ⚙ → 위에 뜨는 목록에서 선택. 고른 테마는 기억됨
      • 방 나누기 — 주소 끝에 #방이름, 같은 방끼리만 대화가 보임

      ⚠️ 링크를 아는 누구나 볼 수 있어요. 업무·개인 정보는 적지 마세요.
